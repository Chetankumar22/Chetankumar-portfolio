# Chetankumar Sirokha — Portfolio

This is a static, responsive freelancer/job portfolio website.

## Files
- `index.html` — complete portfolio website
- `Chetankumar_Sirokha_Resume.pdf` — resume download

## Publish it for a public link
### GitHub Pages
1. Create a GitHub repository, e.g. `chetankumar-portfolio`.
2. Upload both files.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. GitHub will provide a public `github.io` link.

### Netlify
Drag the folder contents into Netlify's site deployment area to get a public URL.

## Before publishing
Add your LinkedIn and GitHub URLs if you want them displayed. They were intentionally not invented because they were not present in the supplied resume.
